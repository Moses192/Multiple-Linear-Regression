# Multiple-Linear-Regression
This project implements Multiple Linear Regression to predict a target variable using multiple independent variables. It demonstrates feature selection, model training, prediction, and evaluation for multivariable regression problems.
## Procedures
1.Import the required libraries.
2.Load the dataset.
3.Explore and clean the data if necessary.
4.Select multiple predictor variables (X).
5.Select the target variable (y).
6.Split the dataset into training and testing sets.
7.Train the Multiple Linear Regression model.
8.Predict outcomes on the test dataset.
9.Evaluate model performance using regression metrics.
10.Interpret the influence of each predictor variable.
